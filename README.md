I made jumping feel WAY better in Godot!

In this projecy, we take a basic platformer jump and improve it using a bunch of techniques commonly used in polished platformer games.

We'll build:

• Variable jump height
• Coyote time
• Jump buffering
• Fall gravity
• Apex gravity
• Air acceleration & deceleration
• Squash & stretch

And as a bonus, we'll make the character sprite react to movement with a simple squash and stretch effect.

Everything is built from scratch in Godot, but the concepts can be applied to pretty much any game engine.

If you're working on a platformer and your movement feels a little... dead, hopefully this helps!
